# Módulo 3. Herramientas de Ciencia de Datos y Machine Learning

Material de estudio, ejercicios y proyectos relacionados con el análisis de datos y el aprendizaje automático.

## Contenido

- Estructura de datos y manejo de la librería Pandas.
- Análisis, visualización de datos y estadísticas básicas.
- Técnicas de regresión y análisis de componentes principales (PCA).
- Clasificación y regresión con Machine Learning.

## Archivos

En esta carpeta se almacenarán:

- Notebooks de Jupyter (`.ipynb`).
- Scripts de Python (`.py`).
- Bases de datos Excel y CSV.
- Modelos de Machine Learning.
- Gráficas y visualizaciones.
- Reportes y documentación en PDF y TXT.
