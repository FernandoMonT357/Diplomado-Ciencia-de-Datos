# Diplomado de Ciencia de Datos e Inteligencia Artificial

Repositorio académico de ejercicios, prácticas, materiales de estudio y proyectos desarrollados durante el **Diplomado de Ciencia de Datos e Inteligencia Artificial** de la Universidad Autónoma Chapingo.

## Descripción general

Este repositorio tiene como finalidad organizar, documentar y conservar los conocimientos adquiridos durante los cinco módulos del diplomado.

Contiene materiales de estudio, notebooks de Jupyter, ejercicios de programación, bases de datos, documentos PDF, archivos Excel, CSV y proyectos prácticos relacionados con la Ciencia de Datos, Machine Learning y Deep Learning.

Se busca mantener un historial de los trabajos realizados y facilitar su consulta, revisión y reproducción.

## Objetivo académico

Desarrollar habilidades para procesar, analizar e interpretar conjuntos de datos mediante herramientas estadísticas, programación en Python y técnicas de inteligencia artificial, con especial atención a sus aplicaciones en el sector agrícola.

## Contenido del diplomado

### Módulo 1. Fundamentos de Programación

Introducción a la programación utilizando Python como herramienta principal para el procesamiento de información y la resolución de problemas computacionales.

**Temas principales:**
- Fundamentos de programación en Python.
- Operaciones numéricas y contenedores.
- Estructuras de control de flujo.
- Manipulación de archivos.

**Carpeta:** `01_Fundamentos_de_Programacion/`

### Módulo 2. Introducción a la Estadística para Ciencia de Datos

Estudio de los conceptos estadísticos y métodos de análisis necesarios para comprender, explorar e interpretar conjuntos de datos.

**Temas principales:**
- Conceptos de estadística.
- Análisis exploratorio de datos.
- Regresión y correlación.
- Aplicaciones estadísticas en Ciencia de Datos.

**Carpeta:** `02_Estadistica_para_Ciencia_de_Datos/`

### Módulo 3. Herramientas de Ciencia de Datos y Machine Learning

Aplicación de herramientas computacionales para la manipulación, análisis, visualización y modelado de datos mediante técnicas de aprendizaje automático.

**Temas principales:**
- Estructura de datos y manejo de la biblioteca Pandas.
- Análisis, visualización de datos y estadísticas básicas.
- Técnicas de regresión y análisis de componentes principales (PCA).
- Clasificación y regresión con Machine Learning.

**Carpeta:** `03_Herramientas_de_Ciencia_de_Datos_y_Machine_Learning/`

### Módulo 4. Redes Neuronales Aplicadas a Imágenes

Estudio de las redes neuronales convolucionales (CNN) y sus aplicaciones en el procesamiento y análisis de imágenes.

**Temas principales:**
- Fundamentos de redes neuronales convolucionales (CNN).
- Preprocesamiento y transformación de datos.
- Arquitecturas avanzadas de CNN.
- Interpretación y visualización de modelos CNN.

**Carpeta:** `04_Redes_Neuronales_Aplicadas_a_Imagenes/`

### Módulo 5. Deep Learning en Aplicaciones Agrícolas

Desarrollo y evaluación de modelos de aprendizaje profundo orientados a la detección de objetos y a la resolución de problemas específicos del sector agrícola.

**Temas principales:**
- Entrenamiento y evaluación de modelos de detección de objetos.
- Arquitecturas avanzadas para detección de objetos.
- Aplicaciones específicas y proyectos prácticos.

**Carpeta:** `05_Deep_Learning_en_Aplicaciones_Agricolas/`

## Herramientas y tecnologías

Las principales herramientas utilizadas durante el desarrollo de las actividades son:

- **Python:** lenguaje de programación.
- **Jupyter Notebook:** desarrollo y documentación de ejercicios.
- **Anaconda:** administración de entornos de Python.
- **Visual Studio Code:** edición y ejecución de código.
- **NumPy y Pandas:** procesamiento y manipulación de datos.
- **Matplotlib y Seaborn:** visualización de información.
- **SciPy:** herramientas de análisis científico y estadístico.
- **Scikit-learn:** desarrollo de modelos de Machine Learning.
- **Git y GitHub:** control de versiones y almacenamiento del proyecto.

Las bibliotecas adicionales para redes neuronales, Deep Learning y procesamiento de imágenes se incorporarán conforme al desarrollo de los módulos correspondientes.

## Consulta de los trabajos

Los archivos se encuentran organizados por módulo y separados en dos categorías:

- **Materiales:** documentos, bases de datos, notebooks originales y recursos proporcionados para el estudio.
- **Tareas:** ejercicios resueltos, prácticas, proyectos y notebooks desarrollados durante el diplomado.

Los notebooks `.ipynb` pueden consultarse directamente desde GitHub, donde se muestran las celdas de código, explicaciones y resultados almacenados.

## Control de versiones

El repositorio utiliza Git y GitHub para conservar el historial de modificaciones y mantener actualizados los archivos del proyecto.

Los cambios realizados en los notebooks y documentos se registran mediante commits y se publican en el repositorio remoto.
