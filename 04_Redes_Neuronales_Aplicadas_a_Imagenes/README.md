# Módulo 4. Redes Neuronales Aplicadas a Imágenes

Material de estudio, ejercicios y prácticas relacionadas con redes neuronales convolucionales y procesamiento de imágenes.

## Contenido

- Fundamentos de Redes Neuronales Convolucionales (CNN).
- Preprocesamiento y transformación de datos.
- Arquitecturas avanzadas de CNN.
- Interpretación y visualización de modelos CNN.

## Archivos

En esta carpeta se almacenarán:

- Notebooks de Jupyter (`.ipynb`).
- Imágenes y conjuntos de datos.
- Scripts de Python (`.py`).
- Modelos y configuraciones de redes neuronales.
- Resultados de entrenamiento y evaluación.
- Gráficas y reportes en PDF.
