# Módulo 5. Deep Learning en Aplicaciones Agrícolas

Material de estudio, ejercicios y proyectos relacionados con la aplicación de técnicas de aprendizaje profundo en el sector agrícola.

## Contenido

- Entrenamiento y evaluación de modelos de detección de objetos.
- Arquitecturas avanzadas para detección de objetos.
- Aplicaciones específicas y proyectos prácticos.

## Archivos

En esta carpeta se almacenarán:

- Notebooks de Jupyter (`.ipynb`).
- Conjuntos de datos e imágenes agrícolas.
- Scripts de Python (`.py`).
- Modelos entrenados y archivos de configuración.
- Resultados de entrenamiento y evaluación.
- Gráficas y reportes técnicos en PDF.
